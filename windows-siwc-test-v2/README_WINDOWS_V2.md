# SIWC 真实调用测试包 v2 —— Windows 本地测试说明

大白话版：这套东西是让你在**你自己的 Windows 电脑上**，用你的 ChatGPT Plus 账号，真的去调一次 GPT，看看能不能多轮聊下去。整个过程不买 API、不碰中转站、不动 Box，token 只留在你自己电脑上。

## v2 相对 v1 改了什么

- **授权流程改对了**：v1 用的授权地址和换 token 方式跟官方文档对不上，v2 已按官方文档原文改对。授权时浏览器会自动跳回你电脑上的本地页面，不用你手动复制授权码。
- **对话从两轮加到三轮**：第 3 轮会让 GPT 追问一个需要你做决策的问题（比如耳机选降噪款还是音质款），验证“GPT 提问 → Muse 汇总后问你”这条链路能不能接上。
- **加了断网恢复演示**（可选）：第 2 轮后手动断网再恢复，看能不能用同一份历史接着聊。
- **token 路径统一了**：授权脚本、测试脚本和桥读的都是同一个文件，不用手动拷来拷去。
- **加了一键启动**：双击 `start_windows_test.bat` 就能跑，不用记命令。

## 你需要准备什么

1. 一台 Windows 电脑（你自己的，别用别人的）。
2. 电脑能上网，能打开 chatgpt.com。
3. 你的 ChatGPT Plus 账号是登录状态。

## 第 1 步：装 Python

1. 打开浏览器，去 https://www.python.org/downloads/ ，点那个黄色的 **Download Python** 按钮，下载安装包。
2. 双击安装包，**先勾上最下面那个 “Add python.exe to PATH”**，再点 **Install Now**。
3. 装完后按 `Win + R`，输入 `cmd`，回车，打开黑色窗口。
4. 在黑色窗口里输入 `python --version`，回车。看到类似 `Python 3.13.x` 就说明装好了（3.10 以上都行）。
5. 如果提示找不到 python，就是第 2 步那个勾没打，卸载重装一次，记得打勾。

## 第 2 步：拿到测试包

把 `windows-siwc-test-v2` 这个文件夹整个拷到你电脑上，比如放桌面：`桌面\windows-siwc-test-v2`。

拿到压缩包时，先核对 SHA-256（发布页会给出；不匹配就不要用，重新下载）：

```
certutil -hashfile Muse-GPT通道-V0.1-第四阶段-Windows测试包v2.2.zip SHA256
```

## 第 3 步：跑测试（一键）

双击 `start_windows_test.bat`，它会自己做：装依赖 → 没授权过就跑授权 → 跑三轮真实调用测试。

也可以在黑色窗口里手动跑（先 `cd` 进文件夹）：

```
pip install -r requirements.txt
python siwc_auth.py
python test_siwc.py
```

授权时在浏览器里：登录你的 ChatGPT 账号 → 选你的 workspace → **确认勾选了“允许使用计划用量”** → 点允许。授权成功后浏览器会自动跳回本地页面，显示“授权完成”，不用你手动复制授权码。

**看到什么算成功**：三轮都打印出回复，第二轮的回复里提到了 500 元或者 60cm（说明上下文接上了），第 3 轮提出了需要你决策的问题，最后出现 “全部完成”。

## 第 4 步（可选）：多测几项

```
python test_siwc.py --refresh        # 刷新演示: 换一次 token, 确认新 token 能用
python test_siwc.py --bad-model      # 失败恢复演示: 故意用错模型名, 看错误是不是被好好接住
python test_siwc.py --offline-demo   # 断网恢复演示: 第 2 轮后按提示断网再恢复, 用同一份历史续聊
```

## 第 5 步：把结果发回给 Muse

1. 找到 `siwc_test_result.json` 这个文件（就在 `windows-siwc-test-v2` 文件夹里）。
2. 直接把这个文件发给 Muse 就行。
3. **里面没有 token**，只有回复、用量、耗时、模型，放心发。
4. 千万不要把 `siwc_tokens.json` 这个文件发给任何人，也不要把里面的内容复制粘贴到聊天里。

## 失败了怎么办

- 提示找不到 token 文件：先回去跑第 3 步授权。
- 提示 token 过期：跑 `python test_siwc.py --refresh`，它会演示刷新 token，刷新完再跑一次。
- 提示不合资格（里面有 `subscription_sharing_user_not_eligible`）：说明这个账号/应用现在用不了计划用量，先停下来，把报错发给 Muse。
- 提示用量超限（里面有 `subscription_sharing_usage_limit_exceeded`）：Plus 的计划用量有个 5 小时窗口限制，等几个小时再试，不要反复刷。
- 浏览器没跳回本地页面（一直转圈）：可能是本地回调监听器被防火墙拦了，先检查 Windows 防火墙有没有弹窗问你要不要放行 Python，点了允许再重跑；还不行就把报错发给 Muse。
- 其他报错：把报错原文发给 Muse，不要自己反复试。
- 更详细的恢复办法见 `RECOVERY.md`。

## SSE 长连接检查清单（跑之前先看一眼）

SIWC 调 GPT 用的是流式返回（SSE，一边生成一边发回来）。以下几点决定了它在你电脑上稳不稳：

1. **不要用 trycloudflare 临时隧道**：临时隧道不支持 SSE，流会被卡住。以后桥要对外提供服务，必须走 Cloudflare 命名隧道（要账号 + 域名）。**本次本地测试不走隧道**，直接调 OpenAI，不受这条限制。
2. **VPN**：在中国大陆，调 OpenAI 很可能反而需要开 VPN。VPN 闪断/切换节点会让正在进行的调用中断，中断了不用慌，讨论历史还在，重新跑一轮就能续上。
3. **防火墙**：桥和测试脚本只做**出站**连接，不需要开入站端口；授权那一步会在你电脑上起一个只监听 127.0.0.1 的本地回调，防火墙弹窗问要不要放行 Python 时点允许。
4. **校园网**：如果调不通，先确认 VPN 开着、再试一次；还不行就把报错发给 Muse。
5. **超时**：单次调用超过 120 秒没回完，脚本会记一次失败，不会一直卡着。

## token 放哪里、怎么管（重要）

- token 只存在你自己电脑上的 `C:\Users\你的用户名\.muse-gpt-bridge\siwc_tokens.json`，别无他处。
- **绝不上传到 Box，绝不贴进聊天记录，绝不发给别人**。
- access_token 只有 1 小时有效，过期了脚本会自动刷新（refresh_token 30 天有效，刷新后会换一个新的，重新起算 30 天）。
- 如果你觉得 token 可能泄露了：去 ChatGPT 设置里找到已连接的应用，把这个授权撤掉，再重新跑 `python siwc_auth.py` 拿一套新的。旧的那套撤掉就作废了。
- 换电脑了：token 不跟着走，要在新电脑上重新授权。

## 这个测试包能证明什么、不能证明什么

- 能证明：在你自己电脑上，SIWC 授权通不通、三轮对话上下文接不接得上、GPT 会不会追问需你决策的问题、断网后能不能续聊、token 刷新行不行、失败了报什么错、花了多少 token。
- **不能证明**：桥放 Box 上远程跑合不合规（那是下一步要单独核实的事，远程部署可能要先申请 waitlist）；也不能证明 Muse 连上桥之后整条链路通不通（那要等隧道和连接器就位后再测）。
